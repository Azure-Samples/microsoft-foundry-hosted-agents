# Agent development guidance

This project was built with the microsoft-foundry skill. Before working on or answering questions about Foundry agents, read the microsoft-foundry skill first.

## Repository structure

New documentation files must go under `docs/` (for example,
`docs/research/`) or inside the relevant sample folder. At the repository
root, `README.md` and `LICENSE` are the only documentation files. `AGENTS.md`
itself is an operational instruction file and remains at the root.
